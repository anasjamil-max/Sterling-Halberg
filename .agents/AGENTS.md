# Project Rules

- **Heading Typography Consistency**: All headings (`h1`, `h2`, section titles) must match the main heading styling for `line-height` and `letter-spacing` (`line-height: 0.9` and `letter-spacing: -3px`).
- **Mobile Responsiveness**: All UI changes, layout modifications, components, and typography additions must be fully mobile-responsive across tablet and mobile viewports by default.
